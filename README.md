# Bitcoin Trader Performance vs Market Sentiment

## Objective
Explore how trader performance and risk behavior vary under Fear and Greed market conditions.

## Data
- Hyperliquid historical trader data
- Bitcoin Fear & Greed Index

## Analysis Summary
- Aggregated trade data to daily trader-level metrics
- Merged market sentiment with trader performance
- Analyzed profitability, win rates, and trade sizes under different sentiment regimes

## Tools Used
- Python
- Pandas
- Matplotlib
